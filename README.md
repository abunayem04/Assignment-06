# FitLog

A gym workout tracker app built with Next.js and Tailwind CSS.

## What it does

- Browse workout library from API
- See workout details with instructions
- Add workouts to daily plan (max 5)
- Save workouts for later
- Track completed workouts
- Sort by duration, calories or rating

## Tech used

- Next.js
- React
- Tailwind CSS
- Lucide React icons
- React Hot Toast

## How to run

```bash
npm install
npm run dev
```

Then open http://localhost:3000
