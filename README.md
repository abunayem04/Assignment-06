# FitLog - Assignment 06

A workout tracker app built with Next.js for Programming Hero Assignment-06.

## Live Link

https://assignment-06-wine.vercel.app/

## Features

- Browse workout library fetched from API
- View workout details with instructions
- Add workouts to today's plan (max 5)
- Save workouts for later
- Mark workouts as done
- Sort by duration, calories or rating
- Data saved in localStorage so it stays after refresh
- Responsive design with mobile menu

## Tech Used

- Next.js (App Router)
- React
- Tailwind CSS
- Lucide React icons
- React Hot Toast
- Google Fonts (Oswald, Inter)

## How to Run

```bash
git clone https://github.com/abunayem04/Assignment-06.git
cd Assignment-06
npm install
npm run dev
```

Then open http://localhost:3000
